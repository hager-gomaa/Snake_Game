# 🐍 Snake Game

A classic Snake Game built using Python and Turtle graphics.  
This project demonstrates game logic, collision detection, and interactive design.

---

## 🎮 Features
- Smooth snake movement
- Food generation with random positions
- Score tracking system
- High score tracking
- Self-collision detection
- Wall collision detection
- Restart functionality after game over

---

## 🛠️ Technologies Used
- Python
- Turtle Graphics
- Random module
- Time module
